# Forward (Sign → Text/Speech) — สำรวจว่าโมเดลล่าสุด (v8) จำคำอะไรได้บ้าง

> สำรวจอย่างเดียว **ไม่ได้จูน/แก้โมเดลหรือโค้ดใดๆ** (ไม่แตะ `reverse_text2sign/`)
> โมเดลที่สำรวจ = `models/` (v8: Thai-only landmark encoder ensemble 10.2M + bank 19,620 คลิป; ที่ follow-up หลัง v8 โมเดลไม่เปลี่ยน)
> สคริปต์วิเคราะห์ใช้ embedding ของ `artifacts/runs/enc-v8` อ่านอย่างเดียว

## 0. สรุปสั้นๆ (อ่านอันนี้พอก็ได้)

| คำถาม | คำตอบตรงๆ |
|---|---|
| แม่นแค่ไหน "ท่าเดี่ยวๆ" ของคนที่โมเดลไม่เคยเห็น (คำใน conversation 327 คำ) | **Top-1 ≈ 71 %, Top-5 ≈ 90 %** (925 query, 158 คำที่มี query) |
| ในประโยคต่อเนื่อง (เซ็นช้าๆ สไตล์ห้องแล็บ) | Top-1 ≈ 56–64 %, Top-5 ≈ 78–80 % |
| ในประโยคเซ็นเร็วแบบธรรมชาติ ของคนใหม่ | **Top-1 ≈ 10 %** — ยังใช้งานจริงไม่ได้ |
| คำที่ระบบ "ยืนยัน" (≥ 80 %) | ถูก 94–100 % **แต่มีน้อยมาก** (ส่วนใหญ่ขึ้น `[?]`/"น่าจะเป็น") |
| ปัจจัยที่ตัดสินความแม่น | **จำนวนคนที่เซ็นคำนั้นในข้อมูล** (1 คน → 13 %, 3–4 คน → 53 %, 10+ คน → 86 %) และคำนั้น "หน้าตาท่า" คล้ายคำอื่นไหม |

**ข้อควรระวังสำคัญก่อนเอาไปแต่งประโยค:** ตัวเลขรายคำด้านล่างมาจาก query ที่เป็นผู้เซ็นที่ไม่อยู่ใน train (val/test) เทียบกับ bank
— ใน conversation vocab **57 % ของ query มาจากคนเดียว** (นักวิจัย TSL51, ห้องแล็บ, กล้องนิ่ง) และอีก 31 % จาก TSL-ONE-S (สตูดิโอ, 5 คนใหม่)
คือ "คนใหม่" แต่ **สภาพภาพสะอาด** ผลบนมือถือ/เว็บแคมของคนจริงจะต่ำกว่า (ดู §5)

## 1. วิธีวัด (ไม่เดา)

- Query = คลิปท่าเดี่ยวของผู้เซ็นในกลุ่ม `val`/`test` (คนที่ encoder ไม่เคยเห็น) → เทียบกับ bank ที่มาจากกลุ่ม `train` เท่านั้น
- จำกัดคำตอบอยู่ใน vocab ปิดสองแบบ: `conversation` (327 คำ) และ `daily` (1,366 คำ = default ของแอป)
- เก็บ rank ของคำที่ถูกต้อง → R@1 / R@5 ต่อคำ (ไฟล์ละเอียดทุกคำ: `scratchpad/pw_conversation.csv`, `pw_daily.csv`)
- **จำนวน query ต่อคำน้อยมาก** (median 8 ในคำที่วัดได้, 1 ในหลายคำ) → ค่าต่อคำที่ n = 1–2 เป็นแค่ "ใบ้" ไม่ใช่ความแม่นยำที่เชื่อถือได้ ผมระบุ n ไว้ทุกคำ
- ผลรวมที่ได้ตรงกับรายงาน v8 (TSL51 unseen signer 0.67 ใน conversation vocab, TSL-ONE-S 0.90)

| แหล่ง query (conversation vocab) | n | R@1 | R@5 |
|---|---|---|---|
| TSL51 นักวิจัย (คนเดียว, แล็บ) | 524 | 0.67 | 0.92 |
| TSL-ONE-S (5 คนใหม่, สตูดิโอ) | 288 | 0.90 | 0.99 |
| YouTube ช่องใหม่ | 38 | 0.63 | 0.82 |
| TTRS | 22 | 0.36 | 0.59 |
| th_sl | 53 | 0.32 | 0.40 |

## 2. ระดับ A — **จำได้แม่น** (R@1 ≥ 0.75, query ≥ 8 ครั้ง) ← ใช้แต่งประโยคได้เลย

(ตัวเลข = จำนวน query / จำนวนคนในข้อมูล)

**ทักทาย/มารยาท:** สวัสดี (10/8) · ขอบคุณ (10/7) · ขอโทษ (10/9) · สบายดี (11/6, R@1 ~0.8+)
**คน/ครอบครัว:** แม่ · พ่อ · แฟน (10/7) · เพื่อน · ลูก · หลาน · ปู่ · ย่า · ป้า · ลุง · พี่สาว · พี่ชาย · น้องสาว · น้องชาย · สามี · ภรรยา · ครอบครัว · โสด · หูหนวก
**กริยา/อาการ/ความรู้สึก:** ชอบ · เรียน · ทำงาน · แต่งงาน · เกิด · วิ่ง · อยู่บ้าน · เหนื่อย · เหงา · ร้อน
**สิ่งของ/สถานที่:** แมว · ไข่ · หมู · ขนมปัง · ตลาด · โรงเรียน · วัด(n=2) · ประเทศไทย · ภาษามือ · ชื่อ
**เวลา/อื่นๆ:** เช้า · พรุ่งนี้ · วันหยุด · ด้วยกัน · ทำไม
**ตัวเลข 0–10:** ศูนย์ · หนึ่ง · สอง · สาม · สี่ · ห้า · หก · เจ็ด · แปด · เก้า · สิบ

**ข้อสังเกต:** กลุ่ม "ครอบครัว + ตัวเลข" แม่นเพราะมี ~28–35 คนในข้อมูล (TSL-ONE-S สตูดิโอ) — ท่าแม่นจริง แต่ผลบนวิดีโอมือถือยังไม่ได้วัดรายคำ
คำจากบทเรียนสถานที่/กีฬา/ประเทศใน daily vocab (จีน ลาว เวียดนาม ไต้หวัน ฮ่องกง ฟุตบอล กอล์ฟ เทนนิส บาสเกตบอล มวย ตระกร้อ แบดมินตัน กีฬา ประเทศ เยาวราช จตุจักร) R@1 ≥ 0.8 เช่นกัน แต่เป็นคำที่ไม่ค่อยใช้ในชีวิตประจำวัน

## 3. ระดับ C — **จำไม่ได้/สลับกัน** (R@1 < 0.5 ทั้งที่มี query ≥ 8) ← เลี่ยงในชุดทดสอบหลัก

คำเหล่านี้ **เป็นคำที่ใช้บ่อยที่สุดในชีวิตประจำวัน** จึงสำคัญที่ผู้ใช้ต้องรู้ว่ามันเปราะ:

| คำ | R@1 | ระบบตอบเป็น | หมายเหตุ |
|---|---|---|---|
| น้อง | 0.00 | เขา (8/10) | สรรพนามชี้ → เหมือนกันหมด |
| พี่ | 0.00 | สูง (10/11) | |
| คุณ | 0.00 | ต้อง (8/10) | สรรพนาม |
| อย่า | 0.00 | ไม่ใช่ (10/10) | |
| ง่วง | 0.00 | พูด / จูบ | |
| ถาม | 0.00 | ง่วง (6/10) | |
| ที่ไหน | 0.10 | อะไร (8/10) | คำถามสองคำสลับกันเอง |
| อะไร | 0.20 | ที่ไหน (8/10) | |
| กลัว | 0.10 | หนาว (7/10) | |
| กิน | 0.18 | อาหาร (7/11) | **ในประโยคจริงจะ top-5 ได้** แต่ top-1 ไม่นิ่ง |
| ฉัน | 0.30 | รัก (6/20) | สรรพนาม |
| เรียก | 0.30 | เอา | |
| บ้าน | 0.30 | จูบ (7/10) | |
| ไป | 0.30 | กลับ (7/10) | ในประโยค selftest `ไป` top-1 ถูก — ไม่นิ่ง |

**รูปแบบที่เห็น:** สรรพนามชี้ (ฉัน/คุณ/น้อง/พี่/เขา) + คำถาม (อะไร/ที่ไหน) + กริยาพื้นฐาน (กิน/ไป/บ้าน) → ท่าคล้ายกัน/สั้น/ใช้การชี้
นี่คือจุดที่ข้อมูลน้อยและท่าไม่ต่างกันมาก — **ไม่ใช่บั๊กที่แก้ด้วยการจูน threshold**

## 4. คำที่ยังไม่มีผลวัด (169 คำจาก 327) — อยู่ใน vocab แต่ "ไม่รู้จริง"

คำเหล่านี้อยู่ใน bank (1–5 คน) แต่ **ไม่มี query ของผู้เซ็นใหม่** จึงไม่มีตัวเลข อย่าเอาไปเป็นชุดทดสอบหลักก่อน:
ครู น้ำ ดู นั่ง ประตู ยืน รัก อิ่ม เขียน เดิน เล่น ไก่ ก๋วยเตี๋ยว ขอ ช่วย ดีใจ ตอบ ตำรวจ ผม ผลไม้ พูด ฟัง หนังสือ หนาว หมา หิว อร่อย เข้าใจ เศร้า … (รายการเต็มรันซ้ำได้จากสคริปต์ใน scratchpad)

หลักฐานทางอ้อมจาก `data_test`: **รัก** (4 คน) ติด top-5 อันดับ 4 เท่านั้น, **น้ำ** top-5 ได้, **ดื่ม** อันดับ 1 (ดู §5)

คำนอก conversation แต่อยู่ใน daily (1,366): คำที่มี ≥ 2 คนเซ็น แต่ R@1 รวมต่ำ — **คำที่ query เดียว R@1 เฉลี่ย 0.28** (292 คำ) ⇒ ถ้าจะทดสอบคำนอก conversation อย่าคาดหวังเกิน ~30 %

## 5. ในประโยคจริง (ต่อเนื่อง) — สิ่งที่วัดไว้แล้ว

| ชุดทดสอบ | R@1 | R@5 | หมายเหตุ |
|---|---|---|---|
| TSL51 test (นักวิจัย, เซ็นช้าสไตล์แล็บ) conversation 1× | 0.64 | 0.80 | WER 0.53 |
| selftest 32 วิดีโอ (คลิปจริงต่อกันตามลำดับ TSL) | 0.64 | 0.78 | |
| คนใหม่ภายนอก 6 คน (33 วิดีโอ, 45 คำ) | 0.24 | 0.38 | บทเรียนคำเดี่ยว มี fingerspell/mouth ก่อนหลัง |
| ประโยคธรรมชาติเร็ว (YouTube, 21 ประโยค/75 คำ) | **0.11** | 0.13 | segmentation พัง |
| **data_test** (5 วิดีโอ, 22 คำ) | 9/22 | top-5 16/22 (conv) / 14/22 (daily) | |

ใน selftest, คำที่ top-1 ถูก **ทุกครั้ง** ในบริบทประโยค: ร้อน เหงา ชอบ ไป ภาษามือ โกรธ ขนมปัง แม่ อยู่บ้าน แฟน ทำงาน สวัสดี สบายดี แมว น้องชาย น้องสาว
(ติด top-5 แต่ไม่ top-1: วันนี้ ยาย ง่วง บ้าน ตลาด กิน · หลุดเลย: น้อง คุณ เที่ยว เจ็บ)

**data_test รายประโยค (daily vocab = default)** — ตรงกับของจริงที่คุณมีอยู่แล้ว:

| วิดีโอ | คำอ้างอิง → rank ของคำถูก | ผล |
|---|---|---|
| test1 | สวัสดี 1 · สบายดี 1 · แมว 1 · แฟน 2 · โกรธ 3 · ชอบ 5 · ปรบมือ – | ระบบยืนยัน สบายดี, แมว (ถูก 2/2) |
| พ่อดื่มน้ำ | พ่อ 1 · ดื่ม 1 · น้ำ 1 | พบทั้ง 3 คำ ที่ top-1 แต่ไม่ถึงเกณฑ์ยืนยัน + มี `ข้าว`, `ศูนย์` แทรก |
| ฉันปลอบเพื่อนร้องไห้ | เพื่อน 1 · ฉัน 1 · ปลอบใจ – · ร้องไห้ – | ได้ 2/4 |
| ฉันรักเพื่อน | ฉัน 3 · รัก – · เพื่อน – | แทบพลาดทั้งประโยค |
| ไปทานข้าวด้วยกันมั้ย | ไป 1 · ข้าว 5 · กิน – · ด้วยกัน – · ไหม – | ได้ 1/5 |

บทเรียน: **คำที่แยกยากใน data_test (ฉัน รัก กิน ข้าว ไหม ปลอบใจ ร้องไห้)** ตรงกับระดับ C/ไม่มีผลวัดในตารางข้างบนพอดี และ **ไหม** ไม่มีท่ามือในข้อมูลเลย

## 6. ไกด์ไลน์ — แต่งประโยคทดสอบ

**หลักการ**
1. ใช้ลำดับคำแบบ TSL ที่โมเดลเคยเรียน (`models/grammar.json`): `OBJ SUBJ VERB` / `PLACE SUBJ VERB` / `TIME SUBJ VERB` / `GREET SUBJ STATE` / `SUBJ STATE ADJ` ฯลฯ
   (ผู้ใช้เซ็นตามลำดับ TSL; ระบบเรียงเป็นประโยคไทยให้ทีหลัง)
2. **แยกชั้นความยาก** เพื่อรู้ว่าพังเพราะอะไร (A = แม่นล้วน, B = ปน 1 คำเสี่ยง, C = ทดสอบสรรพนาม/คำถาม)
3. ใช้ **คนเซ็นที่ไม่อยู่ในข้อมูล** (ไม่ใช่นักวิจัย TSL51 / ไม่ใช่คนที่เคยบันทึกเป็นแหล่ง) เซ็นอย่างน้อย 2–3 คน × 2–3 รอบ
4. เซ็นชัด หยุดสั้นๆ ระหว่างคำ ท่อนบนถึงเอวอยู่ในเฟรม (ดู framing guide: เห็นใต้ไหล่ ≥ ~1 ช่วงไหล่)
5. วัด: R@1/R@5 ต่อคำ, WER, **จำนวนคำที่ยืนยัน (≥ 0.8) และความถูกต้องของมัน** แยกตามชั้น — ห้ามกลับมาจูนจากชุดนี้ ถ้าจะจูนให้สร้างชุด tune แยก
6. ตั้งความคาดหวัง: ชั้น A ≈ 0.6–0.9, ชั้น B ≈ 0.4–0.6, ชั้น C ≈ 0.1–0.3 (ตามตัวเลขข้างบน ไม่ใช่เป้าหมาย)

| อา เหนื่อย | อาเหนื่อย | อา ↔ น้า |
| ขนมปัง แม่ กิน | แม่กินขนมปัง | กิน (top-5) |

### ชั้น C — ทดสอบจุดอ่อน (คาดว่าพลาด; ใช้ดูว่าพลาดเป็น `[?]`/ใกล้เคียง ไม่ใช่มั่ว)
| ลำดับเซ็น | ประโยคไทย | จุดทดสอบ |
|---|---|---|
| ขนมปัง คุณ กิน | คุณกินขนมปัง | คุณ → ต้อง |
| พรุ่งนี้ คุณ ข้าว กิน ไป ที่ไหน | พรุ่งนี้คุณไปกินข้าวที่ไหน | ที่ไหน ↔ อะไร, ไป, กิน, ข้าว |
| คุณ ชื่อ อะไร | คุณชื่ออะไร | คุณ, อะไร |
| ฉัน กลัว | ฉันกลัว | ฉัน → รัก, กลัว → หนาว |
| บ้าน พ่อ ไป | พ่อไปบ้าน | บ้าน → จูบ |
| อย่า ไป | อย่าไป | อย่า → ไม่ใช่ |

**ไม่ควรใช้ใน "ชุดทดสอบจริง" ตอนนี้:** ไหม/มั้ย (ไม่มีท่ามือในข้อมูล เป็นสีหน้าเท่านั้น), ปลอบใจ, ร้องไห้, รัก (ข้อมูล 1–4 คน ไม่มีผลวัด), และกลุ่ม 169 คำใน §4 จนกว่าจะมีข้อมูลเพิ่ม

## 7. ข้อจำกัดของรายงานนี้ (บอกตรงๆ)

- ตัวเลขรายคำใช้ query น้อย (คำละ ~8–10 ครั้งจากคนเดียวในหลายคำ) ⇒ ช่วงความเชื่อมั่นกว้าง; "ระดับ A" หมายถึงสัญญาณดี ไม่ใช่การรับประกัน
- ยังไม่ได้วัดรายคำบนวิดีโอมือถือ/เว็บแคมของคนจริง (ข้อมูลที่มี: external 33 วิดีโอ, data_test 5 วิดีโอ, ประโยคธรรมชาติ 21 ประโยค — รวมทุกคำน้อยเกินแตกรายคำ)
- Top-1 ในท่าเดี่ยว ≠ ผลในประโยคต่อเนื่อง: ทั้งหมดผ่าน segmentation + decoder ซึ่งยังเป็นจุดอ่อนหลักตอนเซ็นเร็ว
- ไม่ได้รันโมเดลบนวิดีโอใหม่ในรอบนี้ ใช้ embedding/ผลที่คำนวณไว้แล้วใน `artifacts/` ตามที่คุณสั่งให้สำรวจอย่างเดียว

เมื่อทำชุดทดสอบจริงเสร็จ แนะนำให้เก็บผลเป็นรายคำตามชั้นเดียวกันนี้ เพื่อเทียบกลับกับตาราง §2–3 ว่าที่วัดในแล็บตรงกับของจริงแค่ไหน
