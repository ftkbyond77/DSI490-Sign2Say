# Boom — branch boom

ดูสำเนาจาก GitHub ใน git_boom/

- DIFF_FROM_MAIN.tsv: รายชื่อไฟล์ที่ต่างจาก main รวมไฟล์เพิ่ม แก้ และลบ
- CORE_CHANGES.patch: diff ของ pipeline, spotting และโมดูลหลัก
- สำเนา Git ไม่รวมงาน local ที่ยังไม่ commit และไม่ได้ merge เข้าระบบที่กำลังรัน
- main เป็นฐาน จึงไม่มี diff ของตัวเอง; ไม่ใช้รายการนี้ตัดสินผู้เขียนแต่ละไฟล์
