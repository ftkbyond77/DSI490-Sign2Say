ใช้คลิปจาก `/Users/thawaphorn/Pee4/Term1/DSI490/data/videos` รหัส 919, 1577, 36827, 1866, 1289 เท่านั้น เปลี่ยน `VIDEO_DIR` และ `IDS` ใน core.py เพื่อเปลี่ยนชุดอ้างอิง

## เปิดใช้งานบนเครื่องนี้

ดับเบิลคลิก `run.command` หรือรันจาก Terminal ด้วย `bash run.command` ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8501

## ข้อจำกัด

- นี่เป็นต้นแบบค้นหา 5 คำ ยังไม่ใช่ฐานข้อมูลทั้งชุด และยังไม่ได้วัดความแม่นยำกับผู้ทำท่าคนใหม่
- เลือกคลิปตัวอย่างที่มีอยู่ในฐานข้อมูลจะทดสอบการจับคู่ไฟล์เดิมเท่านั้น
- ใช้ MediaPipe Holistic จากสคริปต์เดิม แต่เปลี่ยน matching เป็นพิกัด x/y ตามไหล่ พร้อม mask ข้อมูลที่หาย ไม่มีการเติมมือที่หายทั้งคลิปด้วยศูนย์เป็นหลักฐาน
- ลดจำนวนเฟรมเหลือไม่เกิน 80 เฟรมและใช้ exact DTW เฉลี่ยตาม path จึงเทียบตัวเลขกับผล 0.31/3.71 จากสคริปต์เดิมโดยตรงไม่ได้
- มือซ้าย/ขวากลุ่มละ 25% และ pose 50%; เมื่อมือหาย เปรียบเทียบเฉพาะกลุ่มที่มีข้อมูลร่วมกัน จึงอาจเอนเอียงเข้าหาคลิปที่ข้อมูลมือน้อย
- ไม่มี threshold ปฏิเสธคำที่ไม่รู้จัก: อันดับแรกไม่รับประกันว่าถูกต้อง และระยะไม่ใช่ความมั่นใจ
- เก็บ keypoints cache ใน cache/; ไม่เก็บไฟล์อัปโหลดหลังจบการประมวลผล

## ติดตั้งใหม่

ใช้ Python 3.11 สร้าง virtual environment แล้ว `pip install -r requirements.txt` จากนั้น `streamlit run app.py --server.address 127.0.0.1`
