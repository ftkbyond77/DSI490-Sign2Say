# รายละเอียด 5 ช่วง — baseline เดิม

เฟรม 0-based ที่ 25 fps ช่วง [start,end) ไม่ใช่เลขเฟรมต้นฉบับ ~30fps; ช่วงเหล่านี้เป็นผล tagger + window/DP decoder + postprocessing ไม่ใช่ขอบเขตจาก tagger ล้วน

Observed rate: จำนวน browser frames ที่พบ xy มือไม่เป็นศูนย์ / browser frames ที่ timestamp อยู่ในช่วง ก่อน interpolation และ reflection; ซ้าย/ขวาตาม extractor เดิม ไม่ใช่ด้านซ้าย/ขวาของภาพ และไม่ใช่ความแม่นยำของ landmark

ระบบมี p_correct ต่อ segment เท่านั้น ไม่มี p แยกให้แต่ละอันดับ จึงไม่สร้าง softmax แทน p หรือทำซ้ำค่า p ให้ทั้ง 5 คำ

production_score คือ score ที่เว็บใช้: ใน config นี้ exact_rescore=false, prior/CSLS เป็นศูนย์ เป็นค่าสูงสุดของคะแนน concept จาก windows ที่ร่วม ensemble (แต่ละ window ใช้ mean ของสอง cosine สูงสุดตาม Bank.scores ซึ่งมี fallback เมื่อมีตัวอย่างเดียว/คะแนนเท่ากัน) อันดับเรียงจาก temporal_support ไม่ใช่ score สูงสุดเดี่ยว; whole-segment cosine เป็น diagnostic คำนวณใหม่จาก span embedding ของทั้งช่วง โดยใช้กติกา Bank.scores เดิม ไม่ได้ใช้เปลี่ยนอันดับเว็บ
