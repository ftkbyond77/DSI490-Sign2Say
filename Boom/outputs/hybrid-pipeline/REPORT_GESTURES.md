## การอ่านผล

- supported = ผ่านเกณฑ์เชิงเรขาคณิตที่ตั้งไว้ ไม่ใช่ probability หรือการยืนยันว่าท่าถูกตามภาษา
- not_supported = หลักฐานไม่ผ่านเกณฑ์ ไม่ได้พิสูจน์ว่าไม่มีท่านั้น
- insufficient_data = ข้อมูลไม่พอ โดยเฉพาะมือที่หาย ไม่ให้คะแนนลบท่าเพราะ detector หาย
- four_fingers_curled หมายถึงนิ้วชี้–ก้อยงอ ยังไม่ยืนยันกำมือครบเพราะรูปนิ้วโป้งไม่ได้จัดประเภท
- palm_facing/contact เป็น unknown_2d เสมอ; รูปฉายอาจทำให้ข้อนิ้วเหยียดดูงอหรือกลับกัน
- เพิ่มผลตรวจเป็น diagnostic ใน pipeline ทดลองก่อน ยังไม่ใช้เปลี่ยนคะแนนคำอัตโนมัติ เพราะไม่มี label ท่ารายเฟรมสำหรับสอบเทียบ ผลรู้จำและขอบเขตช่วงตรงกับ baseline ไม่ merge
- ผ่าน synthetic/unit tests 27 ข้อ; ไม่รัน clip3; hashes โมเดลก่อนหลังตรงกัน
