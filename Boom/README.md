# การทดลอง DSI490

รวมไฟล์ที่ผู้ช่วยสร้างในพื้นที่ทำงานเดิมของงานนี้ ย้ายมาเก็บใน DSI490

- `book-catalog/`: ตารางคำอธิบายท่าภาษามือ 473 รายการ พร้อม JSON และภาพอ้างอิง
- `outputs/`: โค้ดและผลทดลองเดิม เช่น SignBERT demo, hybrid pipeline, การตรวจคำ และรายงานทดลอง
- `work/`: สคริปต์เตรียมข้อมูล, OCR, ไฟล์ระหว่างทดลอง และสภาพแวดล้อม Python เดิม

โฟลเดอร์เดิมเป็น symbolic link มายังที่นี่ เพื่อคงพาธที่สคริปต์และ Python environment เดิมอ้างถึง ไฟล์จริงอยู่ในโฟลเดอร์การทดลองนี้

ไฟล์ในโปรเจกต์ DSI490-Sign2Say และข้อมูลต้นฉบับไม่ได้ย้ายในรอบจัดระเบียบนี้ งานทดลองใหม่ให้สร้างเป็นโฟลเดอร์ย่อยภายในที่นี่
